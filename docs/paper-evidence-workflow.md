# 论文收录的图表证据与发布流程

论文库一条记录对应一份可精读的论文报告。选题、下载、写五个标题、页面能加载、构建成功，任何一项单独成立都不代表精读完成。每篇必须先确定固定版本和证据，再写解释并发布；图表是论证的一部分，不是报告写完后的装饰。

## 从候选到报告

1. **Daily 记录候选，不批量发布短报告。** 记录问题、候选论文和纳入理由即可。决定精读后用 `npm run new:paper -- <id> <direction>` 建立 `draft: true` 的稳定记录。草稿不出现在论文库。
2. **固定来源并先列证据。** 把 `paper_url` 固定到 arXiv `vN`，核作者与单位；下载该版 PDF、HTML、LaTeX 到 `.paper-cache/<id>/`。先读正文和附录，做一张图表账本：方法对应哪张 Figure、实验配置对应哪张 Table、主结果/消融/失败条件对应哪些 Figure 或 Table。原文缺表时先记录缺口并停在草稿，不能找无关表格凑数。
3. **先提取源码原图，再裁原表。** 在固定版本 LaTeX 包中沿 `includegraphics` 与 caption/label 找到原资产，将路径、引用它的 TeX 文件、图号/label 和用途记录到 `scripts/figure-crops/<id>.json` 的 `sourceAssets`，运行 `npm run papers:source-figures -- <id>`。原资产为 PDF 时渲染该独立图片，不去截论文页面；多面板保持原顺序、图例和坐标。表格由 LaTeX 排版时，在 `crops` 中记录 PDF 页码和紧贴图表边界的矩形，运行 `npm run papers:pdf-figures -- <id>`。不截整页，不包含相邻正文、页眉、参考文献。若图由 TikZ/PGF 内联绘制、确无独立资产，记录 `sourceUnavailableReason` 才允许局部裁图；不得自动执行不可信 TeX。`figures.json` 保存源码包、资产与 TeX 校验值，或 PDF 校验值、页尺寸和裁剪框。逐张放大与原文对照，确认表头、末行、图例和所有子图后，才设置 `visuallyVerified`；工具不会自动批准新图。
4. **围绕证据写五个模块。** 背景分别解释问题背景、前置知识、已有工作与本文位置；方法沿输入、关键状态、训练/推理流程解释方法图；有官方代码就固定 commit、带行号链接和关键源码代码块，核输入形状、关键分支与梯度路径。实验写模型、训练数据、benchmark、指标、超参和算力账本。结果至少放两张原始图表证据，其中要有主结果与一个对照/消融/机制证据；实验或结果模块还要展示一张与论证相关的原论文表格截图。每张图表旁写清读法、条件、数值和结论边界，不能只放链接或转述几个数字。
5. **先审再发布。** `npm run papers:quality` 检查新报告和已纳入门槛的报告；`npm run papers:quality:strict` 检查所有已发布报告。然后人工核对内容事实、图意和页面布局，运行 `npm test`、`npm run build`、`npm run test:browser`，最后才把草稿改成 `draft: false`。CI 也直接运行结构门槛。自动检查能发现缺图、错位和缺出处，不能证明解释正确。

`method_figure` 必须引用正文方法模块中的证据。算法论文用实际方法图；经验诊断论文可用研究设计原表或机制诊断图，但标题必须如实说明类型，不能将结果概览冒充新算法。`figures.json` 的 `role` 是人工分类，填写字段本身不是验证。综述的分类图、对照矩阵和报告清单也不得冒充作者自己的训练实验。

## 历史欠账如何处理

2026-10-03 的复查发现，上一轮即使通过 39/39 结构检查，仍有 21 篇使用近整页截图、图文用途错配和重复通用说明。这是检查规则的漏检，不能据此宣称全库质量一致。本次重新选择源码原图与局部原表、修复同一行 `$$…$$` 公式解析，并移除页面质量等级徽章。自动检查新增源码出处、PDF 页尺寸/裁图比例与 KaTeX 错误检查；它仍不等价于事实审稿或训练复现。

历史报告对应的固定 PDF 版本、页数与校验值见[原文清单](./paper-source-inventory-2026-10-01.md)。内容中的通用背景不能代替论文专属推导、实验参数和源码核读；未逐函数验证、未训练复现之处必须继续明确标注。

修复历史报告按同一流程进行：先固定来源、登记真正的方法图和原表，再补背景/机制/实验。不要通过扩字、贴无关图或填写核对字段来追求检查通过。没有原文配置表就写可追溯的配置账本，不用参考文献页或结果页填空。不要用统一损失公式冒充每篇的专属方法；通用基线公式必须明确标为比较基线。

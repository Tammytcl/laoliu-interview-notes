# 单篇精读深度标准：以 DDPM 为对照

标准样稿：[Denoising Diffusion Probabilistic Models](../content/papers/diffusion/paper-ddpm.md)。发布新单篇精读时，先从头读一遍这份样稿：它之所以可读，并非因为恰好有五个大标题或约八千字，而是每个事实都能回到固定版本原文、作者代码或原图；读者先学会问题，再读方法，最后知道实验究竟支持了什么。新记录默认 `template_version: 5`、`depth_standard: ddpm`。这个字段表示**写作目标**，不是人工质量认证。当前 39 篇的逐篇现状见[全库审查](./paper-audit-2026-09-30.md)；旧记录尚未全部达到该标准，不能把“已核原文”误读为“深度达标”。

| 阅读任务 | DDPM 样稿中的做法 | 新报告需要交付的内容 |
| --- | --- | --- |
| 建立上下文 | 从生成任务、去噪含义、GAN/score 前作进入具体问题 | 先定义任务与最小概念，再讲前作已经解决什么、剩余瓶颈是什么；至少引用代表原始工作，避免上来就报结果 |
| 解释方法 | 正向/反向公式、变量、训练一步与采样链、Figure 2 | 沿真实输入→中间状态→输出讲解关键步骤；用一个小例子检查公式或伪代码；方法原图放在对应段落并解释每个主要模块/箭头 |
| 伴读源码 | 固定 commit，解释 `q_sample → p_losses → p_sample_loop` | 若官方代码公开，固定 commit，沿 2–4 个核心函数讲输入输出、关键分支、形状/状态与公式对应；未公开则写明确证据，不造函数名 |
| 配置与预算 | 模型结构、数据、优化器、步数、TPU v3-8、采样成本 | 分清训练数据/评测集/指标，记录论文与附录公开的模型、batch、LR、长度/精度、解码、硬件/时间；未公开的资源写缺口和复现影响 |
| 结果证据 | Table 1/2、Figure 5/6 的固定 PDF 裁图，分别说明问题、读法和边界 | 至少方法图、主结果表/图、另一张对照/消融/机制图；每图紧随一段说明坐标/行列、比较对象、数值、可以与不可以推出的结论 |
| 结论 | 区分 FID、似然、采样时间与后续方向 | 限定模型、数据、预算和评测口径；区分作者实测、整理者计算与尚未验证事项，附固定版本与代码出处 |

建议用固定版本 PDF 做一张“证据账本”：每一行写图号/表号、页码、主张、关键数值、对照、裁图文件与完整性检查。图表来自固定 PDF 原页；若原图来自 LaTeX 包，应同时与 PDF 排版和图例核对。只截可独立阅读的图表主体，避免截图左右裁字、子图遗漏、坐标和末行消失。裁图后逐张放大复核，登记 `figures.json` 的 SHA256、`visuallyVerified` 和 `explanation: complete`。报告文字可以概括表，但不要用手抄的几个数字替代关键原表。

写作按以下顺序推进：先读论文与附录，列出准确/不确定事实；再建立问题和前作关系；接着画出方法的数据流并核源码；然后填实验账本；随后选择能支撑核心结论的原图、逐张写解读；最后把结论的适用边界和未披露项写清楚。只有证据账本和正文一致时才改 `draft: false`。遇到没有可发表图片的理论论文，先在报告里解释情况并人工评审图证替代方案；不能靠空图或 AI 合成图满足门槛。

`npm run papers:quality` 是**自动结构与证据初筛**：它检查五模块的最低内容量、固定 arXiv 版本、方法公式（流程型论文可用原图与固定源码对照）、实验账本与算力说明、方法图和至少两张结果证据图、逐图解读，以及 PDF 裁图的出处、人工核对状态和 hash。它有误报与漏报：流程型论文不需要硬补公式，原表后不含“解读”二字也可能讲得充分；反过来，字数和图片达标也不能证明讲解正确。最终必须人工核对数字、图意、源码说法和页面布局。历史报告的文件 hash 暂存于 `content/metadata/paper-depth-legacy.json`；这个名单让旧版短报告继续展示，**并没有使其达标**。新增或修改的单篇报告需要升级结构门槛才可构建。`npm run papers:quality -- --summary` 给出全库紧凑清单，`--audit-all` 给出规则缺口；二者均不替代逐篇人工审查。

每次发表前执行 `npm run papers:quality`、`npm test`、`npm run build`，再打开桌面/手机页面确认图表可读。新图先经本地预览确认，不要只看文件尺寸或页面图片加载成功。若正文改写影响了图号、数值或报告使用的资产，重新跑门槛和页面检查。

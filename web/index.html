新增一篇学习笔记，只需 Markdown。

在项目中执行以下命令，填写生成的草稿，再将 draft 改为 false。

npm run new -- my-question llm

分类可选：。推送到 GitHub 后，页面会自动重新构建。

建议的学习结构

  1. 从问题出发：现象、背景和先修知识。
  2. 核心机制：推导、例子和工程取舍。
  3. 常见误区：说明概念的边界。
  4. 小实验与自检：区分建议练习与真实结果。
  5. 面试表达与原始资料：讲清机制并保留来源。

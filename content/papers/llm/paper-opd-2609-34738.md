## 这篇工作放在 OPD 谱系里的位置

**问题与贡献。** 方法把所有 byte-compatible 的一步完成 token 看作一个集合，监督其总概率质量。它与 BPM 的逐 token 概率路由互补：一个保留合法完成集合，一个尝试建立词表映射。摘要称在数学、代码、科学推理和 1T→35B MoE 场景验证，并报告研究 tokenizer pair 的一步完成覆盖超过 99% compatible teacher mass。

**阅读时要抓住的区别。** 2026-09-28 新稿且代码尚未发布。99% 是特定 tokenizer pairs 的局部分析结果，不应外推为所有 tokenizer 组合。

## 机制与证据

**方法线索。** 方法把所有 byte-compatible 的一步完成 token 看作一个集合，监督其总概率质量。它与 BPM 的逐 token 概率路由互补：一个保留合法完成集合，一个尝试建立词表映射。摘要称在数学、代码、科学推理和 1T→35B MoE 场景验证，并报告研究 tokenizer pair 的一步完成覆盖超过 99% compatible teacher mass。

**实验边界。** Event-Set Completion Distillation 研究 student 已生成 teacher token 的一段 byte 前缀、但事件尚未完成时的监督。teacher 知道剩余字节必须如何完成，却没有理由规定多个合法 student token 之间的概率拆分。 本条根据 arXiv 官方题名、摘要和作者信息建立，未把摘要中没有披露的训练数据快照、超参数、GPU 型号/数量、GPU-hours 或结果表数字补成事实。完整实验口径以原文对应的实验与附录为准。

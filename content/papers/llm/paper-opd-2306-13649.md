## 1. 背景与已有工作

早期语言模型蒸馏常用固定答案：把训练集答案或 teacher 生成的答案给 student 学，再比较两者输出分布。部署时 student 会逐 token 生成自己的前缀；一旦它写错，后续前缀就可能偏离固定训练轨迹。这个训练与推理的状态分布差异，在模仿学习里是老问题。GKD 把自回归蒸馏明确写成“student 访问状态，teacher 在访问状态上给监督”的交互式模仿学习。

另一条线是损失函数：传统 forward KL 倾向覆盖 teacher 支持集，小 student 容量不足时可能给低质量候选留过多概率；reverse KL 更偏向主模式，但会降低多样性。论文的研究问题既是“用谁生成训练序列”，也是“用何种散度匹配 next-token 分布”。它为后来的 LLM OPD 提供了可以共同描述数据分布与目标函数的坐标系。

## 2. 方法与实现机制

GKD 对每个 prompt 混合固定数据序列与当前 student 生成的序列，比例由 $\lambda\in[0,1]$ 控制；在每个序列前缀上，请 teacher 计算下一 token 分布并最小化某个散度 $D(p_T,p_S)$。$\lambda=0$ 是离线蒸馏；$\lambda=1$ 完全在 student on-policy 轨迹上训练。优化时不穿过离散采样操作反传梯度，因此要分清“student 生成的数据参与目标”与“对采样过程可微”是两件事。

论文把 forward KL、reverse KL 与不同 $\beta$ 的 generalized JSD 放在同一框架。选择 reverse KL 不是必然更好：如果任务需要多种合理表述，它的 mode-seeking 可能牺牲覆盖；若生成质量比多样性重要，可能更合适。GKD 还能与有标量奖励的 RL 微调合并：student 的同一批 rollout 同时接受任务奖励和 teacher 分布约束。读 Algorithm 1 时要追踪固定序列与新 rollout 何时重采、teacher logits 与 student 前缀是否严格对齐。

原文没有为这些实验提供一个可直接指认为“GKD 专用官方复现仓库”的 GitHub 链接；T5X、T5 checkpoint 的被引链接只是基础设施。这里依据公式与 Algorithm 1 核读，不以框架库中的同名训练选项代替该论文实现。

## 3. 实验设置与算力

任务包含 XSum 摘要、WMT 英德机器翻译、GSM8K 算术推理和 FLAN 指令微调，并在迁移上观察 BBH/MMLU。teacher 主要为已经做任务微调的 **T5-XL（约 3B）**；student 分别使用 **T5-small 77M、T5-base 250M、T5-large 800M**，从相应 SFT 起点开始，避免把“能否写出可用轨迹”的冷启动问题混入算法对比。离线对照包含 SeqKD、监督 KD、ImitKD、f-distill；论文还扫 $\lambda$ 与散度类型。

训练细项分别列在附录 Table A.1–A.4，评测指标随任务变化：摘要关注生成质量及多样性，翻译看译文质量，数学看答案正确率。原文并没有给出统一可复核的 GPU 型号、卡数与 GPU-hours，不能把“多一次 teacher 前向”简单等同于训练总成本增加一倍；各任务序列长度、teacher 大小和离线数据生成方式都不同。

## 4. 结果与图表解读

原文 **Figure 1** 汇总三类任务：相对初始 student 的性能提升，on-policy GKD 平均约为常规 KD 提升的 **2.1 倍（摘要）、1.7 倍（翻译）、1.9 倍（算术）**。这是“提升幅度的比值”，不是模型分数提高 210%。Figure 10 还报告任务无关蒸馏后 held-out BBH 与 MMLU 的绝对准确率各约增加 **2 与 1 个百分点**。这些图共同支持 on-policy 数据有益，但不同任务最佳散度并不相同。

Figure 4 的质量/多样性对照说明为什么只看单一准确率会漏掉 reverse KL 的副作用。Figure 5 把 GKD 与 RLAIF 组合，展示减少幻觉目标与保持下游能力可以同时考虑；这不证明任何 reward 与蒸馏权重都能兼容。若复核表格，先固定模型、训练起点、采样温度与评测指标，再比较 $\lambda$；不能把不同 student 容量的绝对分数直接平均当作算法收益。

## 5. 局限、结论与后续阅读

GKD 最持久的价值是把“on-policy 前缀”与“散度选择”明确拆开。它依赖 student 能写出足够有意义的轨迹，也依赖可在这些轨迹上查询 teacher 概率；黑盒 API 只返回文本时，完整词表散度不能直接复现。由 T5 类模型与这些任务得到的结论不能无条件外推到长思维链、不同 tokenizer 的 teacher–student，或多教师领域融合。后续阅读可把 [MiniLLM](#paper=paper-opd-2306-08543) 的序列级 reverse KL、[SimCT](#paper=paper-opd-2605-07711) 的跨词表共同空间放到这两个轴上比较。

## 1. 背景与已有工作

标准 reverse-KL OPD 倾向快速靠近 teacher 的一个高概率模式。对确定性任务这可能有益，但数学推理同一道题常有多个可行步骤；高熵位置代表多条合理路径，不总是噪声。论文观察到 on-policy 蒸馏后 student 的多样性下降，尤其 teacher 在某些前缀本来就不确定时，单纯 reverse KL 可能给不稳定的 top-1 选择。EOPD 的问题是：**能否按 teacher 的局部不确定性调整蒸馏目标，而不是全序列只用一种 KL？**

与 [MiniLLM](#paper=paper-opd-2306-08543) 强调 reverse KL 的序列级收益相比，EOPD 补充了其代价；与 [GKD](#paper=paper-opd-2306-13649) 在整次实验中选不同散度相比，这里强调**同一条序列中不同 token**可能需要不同监督方向。

RKL 的 mode-seeking 性质并非天然错误：当 teacher 在当前位置几乎确定时，集中到主峰能高效传递答案；问题发生在 teacher 熵高、多个词都合理时，采样到某个 student token 后仅围绕少数峰更新，会让其余合理分支迅速消失。论文的切入点因此不是把所有 RKL 换成 FKL，而是问“何时需要覆盖分布、何时应该果断跟随”。这比序列级固定混合更细，因为一条数学推理中，算式结果 token 可能低熵，连接词或等价变形却高熵。

已有替代方案包括 off-policy KD、GRPO、熵 bonus 和 advantage shaping。off-policy 遭遇状态分布偏移；GRPO 需要每题多条 rollout 和可验证奖励；直接熵 bonus 鼓励的是 student 自身随机性，不保证对齐 teacher 的合理不确定性。EOPD 只需 teacher 在 student 轨迹上的局部分布，目标是保留 teacher 的不确定结构，同时维持 OPD 的 on-policy 优点。

## 2. 方法与实现机制

EOPD 先用 teacher 下一 token 分布的熵判断当前位置有多不确定：低熵时 teacher 偏好清楚，保留较锐的 mode-seeking 信号；高熵时提高覆盖多个合理候选的 forward-KL 成分。论文将两类 KL 组合成熵感知目标，同时讨论梯度/熵变化与多样性，避免 student 过早把可行推理支路压成一个模式。读目标函数时要确认混合权重由哪个模型的熵决定，以及是否对权重本身求梯度；否则容易把“teacher 的不确定性”与“student 当前的犹豫”混淆。

![高低熵 teacher 下的师生分布](./assets/papers/paper-opd-2603-07079/figure-6-pdf.png)

teacher 在前缀 $h_t$ 上的熵为

$$H_T(h_t)=-\sum_{v\in\mathcal V}p_T(v\mid h_t)\log p_T(v\mid h_t).$$

标准 OPD 沿 $y\sim p_\theta$ 最小化 $D_{\mathrm{KL}}(p_\theta\|p_T)$。EOPD 用归一化的 teacher 熵构造 token 权重 $\alpha_t$，在低熵区域偏向 RKL、高熵区域注入 FKL：

$$\mathcal L_t=(1-\alpha_t)D_{\mathrm{KL}}(p_\theta\|p_T)+\alpha_tD_{\mathrm{KL}}(p_T\|p_\theta),\qquad \alpha_t=f(H_T(h_t)).$$

这里公式表达的是论文机制：$α_t$ 随局部 teacher 不确定性改变，而不是训练前固定一个全局混合系数。实际计算用 top-$k=16$ 的分布近似 FKL，避免保存完整词表 logits；top-k 外的质量被截断后需要归一化。低熵时 16 个 token 已覆盖大部分概率，近似可靠；高熵时恰恰更可能遗漏尾部，因此 top-k 是效率与分布保真之间的核心权衡。

Figure 6 的左图中 teacher 质量集中在少数 index，student 能贴住主峰；右图 teacher 分布分散，纯 RKL student 只抬高少数 index，未恢复全局结构。这是动机实验，不是语言任务的最终效果。EOPD 的训练循环仍是：student 生成一条 rollout；冻结 teacher 在同前缀前向；逐 token 计算 teacher 熵和混合损失；只更新 student。若改成 teacher rollout，就失去论文要解决的 student-state 分布。

工程上还要统一聊天模板。论文 teacher 是 Qwen3-Instruct 非思考模式，KD 使用相同 teacher template；GRPO 使用 Qwen3-Base 默认模板。官方仓库已确认，复现基线应固定到提交 `a09cc1fa3a457b61515ca1b5f3c3fff2252eccbb`，否则后续默认参数变化会破坏可比性。需要重点核对熵是在温度缩放前还是后计算、top-k 后是否重归一化，以及混合权重是否 stop-gradient。

从梯度方向看，FKL 会对 teacher 有概率而 student 漏掉的候选施加覆盖压力，RKL 则主要惩罚 student 把质量放到 teacher 不认可处。熵门控把这种差异落实到 token 级：确定的数字答案应避免无谓扩散，开放的推理连接处则避免早熟收缩。实现时不能只用采样 token 的单个 log-prob 估熵，因为一个标量无法恢复 teacher 分布；也不能用 student 熵替代 teacher 熵，否则模型自己的不确定性会反过来决定监督强度，改变论文假设。混合前两项的尺度也应校准，否则数值更大的 KL 会掩盖 $\alpha_t$ 的意义。

原文 **Table 1** 的小实验展示高熵 teacher 情况下 top-1 变化比低熵更多，说明高熵不是一个稳定的唯一目标 token。官方 [EOPD 仓库](https://github.com/WLS04/EOPD)已在原文链接；本轮未逐函数核读，后续应查熵是否在温度缩放后计算、top-$k$ 截断怎样影响熵、混合目标是否逐 token 应用。

## 3. 实验设置与算力

作者用 Qwen3-0.6B-Base、1.7B-Base 在 MATH prompt 上训练，4B-Base 用 DAPO-Math-14k；比较 KD、GRPO、普通 OPD 与 EOPD。评测含 MATH500、AMC23、AIME24/25 等六个数学基准，分别给 Avg@8 和 Pass@8。Avg@8 是多次回答的平均正确率，Pass@8 是八次里至少一次正确，两者对模式收缩的敏感性不同。

完整算力要计入 teacher 在 student 轨迹上产生分布 logits、熵计算与 student 生成。主文未给出跨所有设置的 GPU 型号/卡数/GPU-hours；同一模型下的目标函数消融比跨模型绝对成绩更能检验方法作用。

![EOPD、OPD 与 GRPO 的训练配置](./assets/papers/paper-opd-2603-07079/table-8-pdf.png)

这张原表把最容易影响公平性的采样配置放在一起：OPD/EOPD 每题只采一条，GRPO 每题八条；三者学习率、batch、温度和最大长度一致。因而它既是复现账本，也说明不能仅按“训练 iteration”比较成本，应该按实际生成 token 与 teacher 前向次数核算。

| 配置项 | OPD / EOPD | GRPO |
|---|---:|---:|
| 学习率 | $3\times10^{-6}$ | $3\times10^{-6}$ |
| 优化器 / scheduler | AdamW / cosine | AdamW / cosine |
| batch / mini-batch | 128 / 32 | 128 / 32 |
| 每 prompt 样本数 | 1 | 8 |
| 采样温度 | 1.0 | 1.0 |
| top-p | Qwen 1.0；Llama 0.8 | 同左 |
| 最大响应长度 | 4096 | 4096 |
| FKL top-k | 16 | 不适用 |
| epoch | MATH 3；DAPO 2 | MATH 3；DAPO 2 |

off-policy KD 另用学习率 $10^{-5}$、batch 128、3 epoch、cutoff 4096，CE 与 FKL 权重各 0.5。这种差异源于训练范式，不能把 wall-clock 直接归因于损失；GRPO 每题 8 条 rollout，OPD/EOPD 只生成 1 条，采样成本天然不同。学生包括 Qwen3-0.6B/1.7B/4B-Base，teacher 为 Qwen3-8B；0.6B 和 1.7B 用 MATH，4B 用 DAPO-Math-14k。六个数学基准同时报 Avg@8 与 Pass@8，OOD 还含 GPQA-Diamond、MMLU-Pro 和 AlpacaEval 2.0。

论文未披露覆盖全部实验的 GPU 型号、卡数和 GPU-hours，因此只能核实 batch、序列长度和 epoch，不能给出可审计的算力结论。复现建议分别记录 student 生成、teacher 前向、top-k 通信和反向传播耗时；同一随机种子下比较 OPD/EOPD，才能把增益归因于熵感知而非采样噪声。

## 4. 结果与图表解读

**Table 2** 里 1.7B 的 MATH500 Avg@8，普通 OPD **67.76**、EOPD **68.73**，Pass@8 **84.80→87.60**；4B 在 AIME25 的 Avg@8 **12.08→17.50**，Pass@8 **30.00→33.33**。但并非每格都更好：4B AIME24 Avg@8，OPD **18.33**、EOPD **17.92**。这比笼统写“全面提升”更准确。高熵位置可同时影响平均正确率和至少一次答对的概率，结果应分开解读。

原文的多样性与熵图展示目标调整后 student 是否保留更多探索；这些是机制证据，不直接等于“推理质量更强”。最有说服力的链条是：teacher 高熵位置识别 → 目标函数权重变化 → student 分布/轨迹变化 → benchmark 改善。任何环节缺失都可能让收益来自普通超参数调节。

![六个数学基准的主结果](./assets/papers/paper-opd-2603-07079/table-2-pdf.png)

原表按学生规模分三组、每个数据集同时列 Avg@8 和 Pass@8；淡紫色列是 EOPD。读表时应在同一规模、同一训练集内横向比较，不能把 4B/DAPO 的绝对分数和 0.6B/MATH 当作方法增益。粗体与下划线还显示 EOPD 并非每格第一，这正是保留完整表格而不是只摘最佳数字的价值。

三种规模上的平均趋势较稳定：论文汇总 EOPD 相对 OPD 的 Avg@8/Pass@8 提升分别为 0.6B 的 +1.16/+1.37、1.7B 的 +0.99/+2.39、4B 的 +1.80/+5.05。Pass@8 增益通常更大，符合“保留更多合理轨迹”的动机。不过逐格并非全胜：0.6B AMC23 Pass@8 为 55.0，低于 OPD 57.5；1.7B AIME25 Avg@8 为 5.83，低于 OPD 6.25；4B Minerva Avg@8 39.71，低于 OPD 40.08。因而正确结论是跨规模平均改善，不能写成每个数据集绝对领先。

![Pass@k 随采样次数变化](./assets/papers/paper-opd-2603-07079/figure-2-pdf.png)

Figure 2 更直接检验多样性：1.7B 上，AIME24/25 的 EOPD 与 OPD 差距随 $k$ 从 8 增到 128 而扩大；AMC23 在较小 $k$ 有优势，$k=64$ 时趋近。Pass@k 上涨意味着至少存在更多能走到正确答案的分支，不等于单次贪心回答一定更好，也可能增加无效输出。实际部署若只采样一次，应优先看 Avg@8/Pass@1，而不能把高 $k$ 的搜索收益当作免费精度。

OOD 表中，1.7B GPQA-Diamond Avg@8 从 OPD 30.08 到 31.50、Pass@8 从 77.78 到 81.31；MMLU-Pro Pass@1 从 42.26 到 43.20；AlpacaEval LC-WR 从 22.86 到 23.83，但原始 WR 从 29.92 略降到 29.54。这说明熵感知没有明显只记数学，也再次显示指标之间存在取舍。机制分析应和这些结果一起读：teacher 高熵处 student 熵更接近 teacher，只在最终准确率升高时才构成完整证据。

## 5. 局限、结论与后续阅读

EOPD 需要 teacher 的较完整概率分布才能可靠估计熵。若只拿到一个 sampled token 的 log-prob，无法照论文方式判断高熵位置；若不同 tokenizer，还需先建立共同概率空间。它提示一个广义原则：OPD 目标函数应反映 teacher 对局部状态的确定性与任务是否允许多解，而不是固定认为 reverse KL 最优。

局限包括：top-16 在高熵位置可能恰好最不充分；teacher 的高熵既可能代表多解，也可能代表能力不足，EOPD 无法自动区分；当前实验集中于数学，代码、对话安全和事实任务是否同样受益仍未知；高 Pass@k 还需要部署时支付更多采样成本。论文也未报告完整硬件预算，无法判断 FKL 与熵计算相对普通 OPD 的绝对开销。

后续最关键的消融是固定 top-k 概率质量而非固定 token 数，比较 $k=16/32/64$；按 token 类型画 teacher 熵、混合权重与正确率；把“高熵但 teacher 错误”单独分桶；同时报告 pass@1、pass@k、输出长度和每题生成 FLOPs。跨 tokenizer 场景则不能直接比较词表分布，应配合 byte-level 对齐方法。

阅读结论可以压缩为一句话：EOPD 不否定 RKL，而是把 teacher 局部熵当作切换 mode-seeking 与 coverage-seeking 的信号，在多规模数学实验上主要改善了可探索到正确解的概率。它的说服力来自主表、Pass@k 曲线和分布图三类证据相互对照，而不是单一最好数字。

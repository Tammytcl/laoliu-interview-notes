## 1. 背景与已有工作

teacher 与 student 的概率不一致，只说明“有差异”，并不告诉我们更新方向是否让最终答案更正确。某些差异只是用词习惯，某些改变推理支路，某些把 student 从正确路上带走。这篇分析把蒸馏梯度与理想结果方向比较，追问：**哪类 teacher 在 student 访问的决策节点上真正给出了有用的梯度？**

它提醒不要把 teacher 的 benchmark 得分、模型参数量或单个 token 上的高置信度当作唯一选师标准。OPD 的质量要在 student 自己的分叉点上评价，尤其在不同 teacher 的推理风格不同时。

## 2. 方法与实现机制

作者在同一道问题上构造多条 student 生成分支，记录每个分叉的访问次数与成功率。对至少有两个子分支、各有足够访问且成功率不同的节点，可以从后续结果估计“朝正确分支走”的理想方向；再把某个 teacher 给出的 GKD/蒸馏梯度投影上去，用余弦相似度衡量对齐。相似度高意味着局部梯度更可能支持正确路径，但它只是这套采样树与指标下的诊断，不是参数更新后完整训练效果的充分证明。

论文比较自身 teacher、不同上下文的自身 teacher 与外部强 teacher，拆分正确/错误路径。关键警示是：梯度可能在**错误路径上更对齐**，因为那里有更多可纠正的分叉；若只看成功样本的平均 log-prob，会错判 teacher 的价值。

原文没有给出可确认的官方代码仓库。这里描述的是论文 §2 的分析流程，不声称已经运行搜索树或核读函数。

## 3. 实验设置与算力

实验 student 取 Qwen3-0.6B、1.7B，任务为 BoolQ 与 MMLU；论文分析大量分叉决策点，BoolQ 0.6B/1.7B 分别约 **88K/81K**，MMLU 分别约 **49K/46K**。比较八种 teacher 配置，包括自蒸馏与外部模型。有效分叉门槛、每个节点的访问次数和正确率差异决定哪些点进入统计；这会影响指标外推范围。

这是观测研究，算力主要花在多 rollout 构造分叉树和 teacher 在节点上评分。主文没有给出可统一比较的 GPU-hours。若复现，节点采样预算、答案判分器与是否重复 prompt 比“训练步数”更关键。

## 4. 结果与图表解读

论文报告 BoolQ 上总体梯度对齐虽然为正，但很弱：0.6B 平均余弦约 **+0.027**，1.7B **+0.026**，而逐 token 标准差约 **0.83–0.91**。这意味着“平均正向”并不保证某次更新可靠。Figure 3 把正确与错误路径拆开，部分设置在错误路径上反而有更高对齐；这种结果符合“可纠正错误更多”的解释，但不能推广成所有错误回答都应加大训练权重。

Table 1 的 teacher 排名依 BoolQ/MMLU 与 student 尺寸变化，自条件 teacher 在若干配置上领先。读置信区间时需要注意哪些差异稳定、哪些重叠。最有用的不是记住一个赢家，而是建立选师评估方法：在 student 会走到的前缀上测梯度方向与结果关联。

## 5. 局限、结论与后续阅读

理想梯度本身由有限 rollout 估计，成功率标签也可能有噪声；这套分析不是低成本的在线路由方案。它适合离线研究 teacher 选择和信号诊断。后续若把对齐分数用于训练，应额外验证计算开销、分叉采样偏差与下游结果，避免把诊断相关性直接当训练目标。

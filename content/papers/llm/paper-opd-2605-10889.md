## 1. 背景与已有工作

**阅读定位。**《Unmasking On-Policy Distillation: Where It Helps, Where It Hurts, and Why》放在 OPD 文献链条中，核心问题不是把一个最终答案从 teacher 复制给 student，而是 student 先在当前策略下生成前缀，teacher 再对这些真实会遇到的状态提供监督。这样可减少离线 teacher 轨迹与 student 部署轨迹的分布偏移，但代价是每轮都要生成、teacher 前向和更新，稳定性、概率空间以及评测预算会互相耦合。

本报告把贡献拆成“问题假设—训练信号—工程实现—证据边界”四层。与 SFT 相比，OPD 监督的是 student rollout；与 RL 相比，它通常不必为每题设计外部 reward，而以 teacher 分布或似然差为反馈；与离线 KD 相比，它能在 student 的错误前缀上纠偏。若 teacher 与 student tokenizer、终止符或能力分布不同，还会额外出现概率不可比、长度偏差或局部信号失真的问题。阅读原文时应先确认论文解决的是哪一层，而不是把所有提升笼统归因于“on-policy”。

这套定位也限定了结论：论文中的 benchmark 增益只能支持给定模型、数据和预算下的机制，不能自动外推到任意规模或任务。尤其需要区分 teacher 更强带来的上限、训练 token 更多带来的算力收益，以及新目标函数本身的贡献。后文保留原论文图表证据与负结果，避免只摘摘要中的最佳数字。

teacher 与 student 的概率不一致，只说明“有差异”，并不告诉我们更新方向是否让最终答案更正确。某些差异只是用词习惯，某些改变推理支路，某些把 student 从正确路上带走。这篇分析把蒸馏梯度与理想结果方向比较，追问：**哪类 teacher 在 student 访问的决策节点上真正给出了有用的梯度？**

它提醒不要把 teacher 的 benchmark 得分、模型参数量或单个 token 上的高置信度当作唯一选师标准。OPD 的质量要在 student 自己的分叉点上评价，尤其在不同 teacher 的推理风格不同时。

## 2. 方法与实现机制

![Figure 2：分支节点上的梯度对齐估计](./assets/papers/paper-opd-2605-10889/algorithm-figure-pdf.png)

该图由源码中的绘图代码生成，没有独立图片资产，因此仅裁 Figure 2。左侧从学生分支 rollout 估计成功概率与理想梯度，中间由教师前向构造蒸馏梯度，右侧比较两者方向。正对齐表示局部更新方向有利于成功，负值表示冲突；这是一种机制诊断，不是已有训练算法的收益保证。 图表源：[arXiv 2605.10889v1 PDF，第 6 页](https://arxiv.org/pdf/2605.10889v1#page=6)，仅裁图表区域。

作为比较基线，student 轨迹记为 $y\sim\pi_\theta(\cdot\mid x)$，teacher 为 $\pi_T$。常见 token 级 on-policy 蒸馏的示意目标写成下式；它不代表本文所有变体都采用同一散度或同一梯度估计器：

$$\mathcal{L}(\theta)=\mathbb{E}_{x,\,y\sim\pi_\theta(\cdot\mid x)}\!\left[\sum_t D\!\left(\pi_\theta(\cdot\mid x,y_{<t}),\pi_T(\cdot\mid x,y_{<t})\right)\right].$$

这里最关键的是期望分布也依赖 student：参数更新后，下一批前缀会变，teacher 监督的位置随之移动。若实现先缓存 teacher 自己生成的固定答案，目标就退化为 off-policy；若 teacher 和 student 看到的模板、温度或 EOS 不一致，似然差还会混入协议偏差。散度是 reverse KL、forward KL、JS、回归损失还是经过门控的组合，会决定 mode-seeking、coverage 和梯度尺度，不能只用“KD loss”概括。

复现时建议把一次训练 step 拆成六个可审计阶段：固定 prompt 与模板；student 生成并记录 token/终止原因；teacher 在完全相同前缀上前向；构造论文定义的 token 掩码、权重或对齐；只对 student 反向；记录有效 token 数与梯度范数。对于跨 tokenizer 方法，还必须保存共同 byte/event 单元到两侧 token 的映射；对于自蒸馏，必须冻结 teacher 快照或明确同步频率；对于 verifier/多 teacher 方法，则要记录门控拒绝率与各 teacher 被选比例。

公式实现有三个常见陷阱。第一，用 batch mean 代替有效 token mean 会让长回答获得更大权重；第二，teacher logits 的温度缩放、top-k 截断和重新归一化次序会改变目标；第三，在本应 stop-gradient 的权重上反传，会引入论文没有的高方差项。最小测试应构造一个两 token 词表，手算每项概率、mask 与梯度方向，再做端到端小 batch 对照。作者未开源与该论文一一对应的官方代码仓库，因此这里只能依据固定版论文、公式和附录核读，不能声称函数级实现已验证。

方法是否有效不能只看最终 accuracy。还要检查训练中 teacher-student KL、student 熵、回答长度、EOS 概率、有效更新 token 比例、梯度范数和 rollout 成功率。若主指标上涨却长度暴增、熵坍缩或 OOD 明显下降，应视为带代价的权衡。原文方法图、后续配置说明和结果图表共同构成可追溯链条。

作者在同一道问题上构造多条 student 生成分支，记录每个分叉的访问次数与成功率。对至少有两个子分支、各有足够访问且成功率不同的节点，可以从后续结果估计“朝正确分支走”的理想方向；再把某个 teacher 给出的 GKD/蒸馏梯度投影上去，用余弦相似度衡量对齐。相似度高意味着局部梯度更可能支持正确路径，但它只是这套采样树与指标下的诊断，不是参数更新后完整训练效果的充分证明。

论文比较自身 teacher、不同上下文的自身 teacher 与外部强 teacher，拆分正确/错误路径。关键警示是：梯度可能在**错误路径上更对齐**，因为那里有更多可纠正的分叉；若只看成功样本的平均 log-prob，会错判 teacher 的价值。

原文没有给出可确认的官方代码仓库。这里描述的是论文 §2 的分析流程，不声称已经运行搜索树或核读函数。

## 3. 实验设置与算力



| 配置 / 统计单位 | 原文设置 | 解释与边界 |
|---|---|---|
| 学生 | Qwen3-0.6B、Qwen3-1.7B | 两种学生规模分别统计 |
| 教师条件 | 每个学生比较 8 种教师配置 | 包括带特权上下文的同模型和外部教师 |
| 主任务 | BoolQ、MMLU | AIME 的长轨迹分析使用更高有效访问门槛 |
| 目标 token | 学生或教师概率超过 0.02 | 不是对全部词表位置均匀采样 |
| 访问预算 | 每个目标补到至少 100 次访问 | 用于估计分支后的成功概率 |
| 有效子节点 | 每子节点至少 20 次访问；AIME 为 40 次 | 访问不足的节点不进入对齐统计 |
| 生成开销 | 每题约 45K–200K 定向 rollout | 取决于轨迹长度，不是训练 step 数 |
| 复用 | 八种教师共享同一学生生成树 | 教师改变时只重新评分，不能重复计算同一生成开销 |

配置来源：[原文第 6 页的 Budget and scalability 与 Experimental Setup](https://arxiv.org/pdf/2605.10889v1#page=6)。这是观测估计的采样账本，并无统一的学生优化学习率需要填入。

公平对照至少要固定 student 起点、训练 prompt、生成 token 总量和评测解码。只固定 step 不够：多 rollout、更长回答和更大 teacher 会显著增加计算。若论文没有完整 GPU 型号、卡数或 GPU-hours，本报告将其视作披露缺口；复现时需单独测量 student 生成、teacher 前向、反向传播和评测四部分 wall-clock。已有正文中的论文专属模型、数据和参数说明应与这张账本结合阅读。

统计上应报告多个随机种子或置信区间，并把 checkpoint 选择放在独立验证集。Pass@k 会随 k 和采样温度上涨，不能与 greedy accuracy 混写；LLM judge 需要固定版本与 prompt；verifier 过滤后的有效样本量也要报告。只有配置、预算和指标都对齐，结果差异才可归因于方法。

实验 student 取 Qwen3-0.6B、1.7B，任务为 BoolQ 与 MMLU；论文分析大量分叉决策点，BoolQ 0.6B/1.7B 分别约 **88K/81K**，MMLU 分别约 **49K/46K**。比较八种 teacher 配置，包括自蒸馏与外部模型。有效分叉门槛、每个节点的访问次数和正确率差异决定哪些点进入统计；这会影响指标外推范围。

这是观测研究，算力主要花在多 rollout 构造分叉树和 teacher 在节点上评分。主文没有给出可统一比较的 GPU-hours。若复现，节点采样预算、答案判分器与是否重复 prompt 比“训练步数”更关键。

## 4. 结果与图表解读

![Table 1：教师的平均梯度对齐及置信区间](./assets/papers/paper-opd-2605-10889/table-1-results-pdf.png)

原表按数据集和学生规模比较教师的平均梯度对齐，并给出 95% 置信区间。0.6B 学生上自蒸馏与 1.7B 上外部教师的相对排序不同，因此不能用单一教师排名覆盖所有学生。这里的指标是方向相容性，不是蒸馏完成后的准确率；置信区间重叠的小差异也不宜夸大。 图表源：[arXiv 2605.10889v1 PDF，第 8 页](https://arxiv.org/pdf/2605.10889v1#page=8)，仅裁图表区域。

![Figure 3 左图：正确与错误路径的梯度对齐](./assets/papers/paper-opd-2605-10889/alignment-source.png)

原图取自 Figure 3 的 Qwen3-0.6B / BoolQ 子面板，比较通向正确和错误答案的路径。某些教师在错误路径上反而更对齐，解释了局部似然匹配为何可能偏离最终成功目标。这里只展示这一数据集和学生配置，不把单组分布对照图外推为全部任务；完整设置汇总见主表。 图源：[arXiv 2605.10889v1 LaTeX 源码](https://arxiv.org/src/2605.10889v1)，原始文件 `figures/qwen0.6b_boolq/sig_20/msc2_srr0.0001_gz0.0100/correct_vs_incorrect_violin_v2.pdf`。

结果证据应形成闭环：主表回答“最终是否更好”，曲线回答“训练是否更稳/更快”，消融回答“哪个部件起作用”，成本表回答“是否等预算”。任一环节缺失都降低因果强度。尤其在 OPD 中，更强 teacher、更长 rollout 或更多 teacher 前向本身就可能提高分数，因此必须同时报告 teacher 调用量和生成 token。只引用平均值还会掩盖 AIME 这类小样本基准的高方差。

实践决策不能只追最高 accuracy。若目标是单次在线回答，应重视 Pass@1/Avg@k 与延迟；若允许 test-time scaling，才关注较大 k 的 Pass@k；若模型需要持续更新，还要测 OOD、遗忘和连续多轮蒸馏。本文据原图与正文只给“这些实验设置下”的结论，不把局部结果外推成普遍规律。

论文报告 BoolQ 上总体梯度对齐虽然为正，但很弱：0.6B 平均余弦约 **+0.027**，1.7B **+0.026**，而逐 token 标准差约 **0.83–0.91**。这意味着“平均正向”并不保证某次更新可靠。Figure 3 把正确与错误路径拆开，部分设置在错误路径上反而有更高对齐；这种结果符合“可纠正错误更多”的解释，但不能推广成所有错误回答都应加大训练权重。

Table 1 的 teacher 排名依 BoolQ/MMLU 与 student 尺寸变化，自条件 teacher 在若干配置上领先。读置信区间时需要注意哪些差异稳定、哪些重叠。最有用的不是记住一个赢家，而是建立选师评估方法：在 student 会走到的前缀上测梯度方向与结果关联。

## 5. 局限、结论与后续阅读

共同局限可以归为四类：teacher 可能在 student 前缀上失准；on-policy 反复调用 teacher，训练成本高于离线 SFT；tokenizer/EOS/template 不一致会把协议差异伪装成知识差异；多数论文集中在数学或可验证任务，开放式对话、代码和长期遗忘证据仍少。Unmasking On-Policy Distillation: Where It Helps, Where It Hurts, and Why 应在这些边界内理解，不能因一个平均分提升就宣称普遍优于所有蒸馏或 RL 方法。

后续复现优先做等生成 token、等 teacher 前向和等 GPU-hours 三套对照，并报告长度、熵、KL、有效 token、梯度范数、OOD 与失败案例。阅读路线可依次对照普通 off-policy KD、标准 RKL OPD、本文专属改进以及同主题的稳定化/跨 tokenizer 工作。最终判断标准是“收益来自哪里、付出什么成本、在何种条件下失效”，而不是只复述摘要。

理想梯度本身由有限 rollout 估计，成功率标签也可能有噪声；这套分析不是低成本的在线路由方案。它适合离线研究 teacher 选择和信号诊断。后续若把对齐分数用于训练，应额外验证计算开销、分叉采样偏差与下游结果，避免把诊断相关性直接当训练目标。

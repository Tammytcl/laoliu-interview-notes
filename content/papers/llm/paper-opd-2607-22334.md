## 这篇工作放在 OPD 谱系里的位置

**问题与贡献。** 读算法时沿“teacher token bytes → student prefix token → 概率聚合”检查是否守恒；尤其要看不同学生 token 在 teacher token 的 byte 前缀内如何归并。它处理的是跨 tokenizer 概率 routing。

**阅读时要抓住的区别。** 与 ESCD 的重要差异：BPM 主张为学生 token 分配概率；ESCD 对部分进入事件后的多个合法补全监督其总概率，不强行指定内部拆分。

## 机制与证据

**方法线索。** 读算法时沿“teacher token bytes → student prefix token → 概率聚合”检查是否守恒；尤其要看不同学生 token 在 teacher token 的 byte 前缀内如何归并。它处理的是跨 tokenizer 概率 routing。

**实验边界。** Byte-Prefix Marginalization 把 teacher next-token 概率映射到共享 byte 空间，再投到 student 词表，试图避免丢失 teacher 概率质量或分给字节内容无关的学生 token。 本条根据 arXiv 官方题名、摘要和作者信息建立，未把摘要中没有披露的训练数据快照、超参数、GPU 型号/数量、GPU-hours 或结果表数字补成事实。完整实验口径以原文对应的实验与附录为准。
